# 🎓 Student Performance Analyzer

A beginner-friendly Python + Pandas project that analyzes student academic data and generates insights like averages, grades, top performers,
and pass/fail status.

---

## 🚀 Features
- Read data from CSV file  
- Calculate student-wise averages  
- Compute subject-wise averages  
- Assign grades automatically  
- Identify top-performing student  
- Find highest and lowest marks  
- Determine pass/fail status  
- Display clean output  

---

## 🛠️ Tech Stack
- Python  
- Pandas
