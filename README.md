# 📊 Student Performance Analyzer

A Python-based data analysis project that uses **Pandas** to evaluate student performance from a CSV dataset. It calculates averages,
assigns grades, identifies top performers, and determines pass/fail status.

---

## 🚀 Features

- Reads student data from a CSV file  
- Calculates individual student averages  
- Computes subject-wise averages  
- Identifies the top-performing student  
- Finds highest and lowest marks  
- Assigns grades automatically  
- Determines Pass/Fail status  
- Displays clean output  

---

## 🛠️ Tech Stack

- Python  
- Pandas
